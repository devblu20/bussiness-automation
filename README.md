# AutoFlow — Business Automation

A small React + TypeScript website explaining everyday automation for an international audience, with examples across industries and time zones. Vite builds the site. There is no backend or account system to maintain.

## Run locally

```sh
npm install
npm run dev
```

Open http://127.0.0.1:4173. To build for production, run `npm run build`. To preview that build, run `npm run preview` after stopping the development server.

## Where to make changes

| File | Purpose |
| --- | --- |
| `src/content.ts` | Service descriptions, six business examples, and common questions |
| `src/App.tsx` | Page sections, headings, and appearance preference |
| `src/Navbar.tsx` | Desktop/mobile navigation and active section tracking |
| `src/Icon.tsx` | Small, shared Lucide icon collection |
| `src/styles.css` | All styling, theme colours, and responsive layouts |
| `src/main.tsx` | React entry point |
| `public/` | Business team photograph and favicon |
| `index.html` | Page title, metadata, and font links |

Change the colour variables at the top of `src/styles.css` to adjust the light and dark themes. Run `npm run format` after edits; `npm run format:check` checks formatting. `npm run build` checks TypeScript and creates the production output.

## Project folders

- `src/` is the editable application source.
- `public/` contains the site's static assets; credits are in `ASSETS.md`.
- `dist/` is generated by the build. Do not edit it directly.
- `node_modules/` contains installed dependencies and is excluded from Git.
- `.openai/hosting.json` connects this project to its existing Sites deployment.
- `.git/` contains version history and is required for publishing.

Unused SaaS screens, workflow builders, old style layers, one-off migration scripts, and deployment archives have been removed. Production archives should be prepared in a temporary directory, outside the project.

## Website behaviour

The site includes responsive navigation, section links, active section indicators, and light/dark mode. Only the appearance preference is saved in browser storage. Old application hash URLs return to the informational homepage.

All business examples are illustrative. There are no customer accounts, dashboards, pricing plans, live integrations, or automation execution on this informational website.
