# AutoFlow — Business Automation

Informational business website focused on automating everyday activities for Dubai companies. The active entry point is src/main.tsx, rendering BusinessSite.tsx with business.css.

## Run

npm install
npm run dev

Build: npm run build. Vite writes the production website to dist.

## Current website

- Clear service descriptions covering communication, documents, operations, and reporting.
- Six illustrative business examples written as everyday task, possible automation, and practical benefit.
- A short explanation of AI assistance and human review.
- A practical approach and plain-text answers to common questions.
- Responsive navigation, anchor links, and light/dark appearance.

The previous SaaS pages are no longer mounted or linked. Old application hash URLs open the informational homepage. Legacy source modules are retained for reference but are not part of the active site.

There are no customer accounts, dashboards, builders, pricing plans, booking forms, live integrations, or automation execution on this website. Examples describe possible business applications; they are not customer results or service guarantees. Only the chosen appearance is saved in browser storage.
